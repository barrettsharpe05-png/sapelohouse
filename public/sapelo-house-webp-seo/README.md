# Sapelo House WebP Image Package

This package contains 30 WebP images converted from the original iPhone HEIC files.

- Images are in the `images/` folder.
- Filenames are SEO-oriented for Sapelo House, the Sapelo River, and Townsend, Georgia.
- Alt text is included in `sapelo-house-alt-text.csv` and `sapelo-house-alt-text.md`.
- Images were resized to a maximum long edge of 2400px for strong website quality with better page speed.
- WebP files were exported at quality 86 with metadata stripped for web use.
